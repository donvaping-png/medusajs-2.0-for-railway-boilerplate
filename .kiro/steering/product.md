# Product Overview

This is a MedusaJS 2.0 e-commerce boilerplate configured for deployment on Railway. It's a monorepo containing both backend and storefront applications.

## Key Features

- **Backend**: MedusaJS 2.0 commerce engine with admin dashboard
- **Storefront**: Next.js 15 B2C storefront with internationalization
- **Pre-configured integrations**:
  - MinIO for cloud file storage
  - Resend/SendGrid for email notifications
  - Stripe for payments
  - MeiliSearch for product search
  - Redis for event bus and workflow engine
  - PostgreSQL database

## Purpose

Provides a production-ready e-commerce platform that can be deployed to Railway with minimal configuration. Designed for rapid deployment with sensible defaults and fallback options when third-party services aren't configured.
